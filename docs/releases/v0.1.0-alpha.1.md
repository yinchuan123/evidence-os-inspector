## Evidence OS Inspector v0.1.0-alpha.1

First public alpha. **See what changes when your evidence changes.**

Live demo: https://yinchuan123.github.io/evidence-os-inspector/

A browser-only workspace that binds research claims to passages in versioned
source texts, records human reviews against those versions, and shows which
claims need another look when a source or an upstream claim changes. No
account, no upload, no AI model.

### What is in this release
- Versioned sources and claims with SHA-256 content hashes; old versions kept.
- Passage binding by character offset to a specific source version.
- Review labels: supported within stated scope / partially supported / not supported / cannot determine, with rationale and recorded basis.
- Explicit confirmed / unconfirmed dependencies; cycles and dangling references rejected.
- Derived "needs re-review" state with reasons and dependency path; verdicts are never flipped automatically.
- Impact report for a source revision: direct, indirect (confirmed), potential (unconfirmed), unaffected.
- JSON export/import (`eosi-workspace` 0.1) with full validation; standalone HTML report with no scripts.
- Three synthetic demos; English and Simplified Chinese UI; desktop and narrow layouts; strict CSP (`connect-src 'none'`).

### Known limitations
- Plain text only: paste, `.txt`, `.md`, or the tool's JSON. No PDF/OCR.
- Demo texts are English; the interface is bilingual.
- Work lives in the browser tab (plus session storage); export JSON to keep it.
- Alpha: expect rough edges. Please report what you tried.

### Assets
- `evidence-os-inspector-v0.1.0-alpha.1-site.zip`: production build of the static site (built with base path `/evidence-os-inspector/`; serve it under that path, or rebuild with `VITE_BASE=/`).

- `demo-en.mp4`, `demo-zh.mp4`: 40-second captioned recording of the correction demo.
