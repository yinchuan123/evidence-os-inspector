## Evidence OS Inspector v0.1.0-alpha.3

Point release from the post-release verification of alpha.2. Two independent checkers re-tested each fix from the pre-launch review on the live site; the eight that were re-checked held, and the checkers found four adjacent defects in the same code. All four are fixed here.

Live demo: https://yinchuan123.github.io/evidence-os-inspector/

### Fixed
- **Id overflow on import.** An id number beyond the exact-integer range (for example `ev_99999999999999999999`) was accepted; every object created afterwards received the same id and silently overwrote the last one. Ids and `nextId` are now bounded at 2^48 and out-of-range values are refused.
- **Importer crash on inherited type names.** A history event with type `constructor`, `__proto__` or `toString` made the importer throw and show an internal message. It now returns a normal validation error.
- **"New workspace" inside a demo discarded your own workspace.** Inside a demo the button now reads "My workspace" and only opens your workspace. In your own workspace the prompt names the workspace and the number of claims and sources it would discard; an empty workspace is replaced without asking.
- **Imported demo files vanished on refresh.** A JSON exported from a demo and imported as your workspace was not saved. Imported files now become your workspace and persist, including later edits; importing while viewing a demo moves you to your workspace.
- Review labels outside the four allowed values now get an error naming the allowed labels.

### Tests
Nine new unit tests and four new end-to-end flows. Each new test was checked by putting the defect back and confirming the test fails. The demo flow now also records requests made while the page loads.

### Unchanged
Core model, JSON format version (0.1), demos, CSP. Files exported by alpha.1 and alpha.2 import unchanged unless they contain one of the malformed ids described above.

### Assets
`-site.zip` (static build, base `/evidence-os-inspector/`, includes `BUILD_INFO.txt`), `-source.zip`, `demo-en.mp4`, `demo-zh.mp4`, `SHA256SUMS.txt` (with commit and build provenance).
