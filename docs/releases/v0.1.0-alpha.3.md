## Evidence OS Inspector v0.1.0-alpha.3

Point release from the post-release verification of alpha.2 on the live site. Two independent checkers re-tested each of the eleven fixes from the pre-launch review: all eleven held. The checkers and a three-lens regression sweep (interface, privacy and security, docs versus code) then found further defects; the ones that stood after adversarial verification are fixed here.

Live demo: https://yinchuan123.github.io/evidence-os-inspector/

### Data safety
- **Id overflow on import.** An id number beyond the exact-integer range (for example `ev_99999999999999999999`) was accepted; every object created afterwards received the same id and silently overwrote the last one. Ids and `nextId` are now bounded at 2^48.
- **Built-in names as references.** A reference such as `constructor` or `__proto__` could pass the integrity check, and an event type with such a name crashed the importer. References now resolve only to records in the file; both cases return a normal validation error. Duplicate history event ids are refused.
- **"New workspace" inside a demo discarded your own workspace.** Inside a demo the button now reads "My workspace" and only opens your workspace. In your own workspace the prompt names the workspace and how many claims and sources it discards.
- **Imported demo files vanished on refresh.** An imported JSON now becomes your workspace and persists, including later edits.

### Interface
- Claims without a label were shown by internal id (`clm_2`) in the impact banner, history and report while the list showed "1", "2". All views now use the list position.
- On desktop the page could scroll about 400px past the layout, taking the header with it. Fixed.
- Review and history times are shown in local time instead of unlabelled UTC.
- The review form no longer pre-selects "Supported within stated scope"; a label must be chosen. The state and the last verdict are shown separately.
- Space on a claim card no longer scrolls the list. Chinese mode translates the remaining accessibility labels and the recording's alt text, stops marking your own text as English, and links to the Chinese FAQ section.
- The desktop header fits on one row at 1280px in both languages; the duplicate "Home" button is gone (the app name links back to the start page).
- Clearer counters, report columns "Created" / "Time", a distinct file name for the report with full source text, and no duplicate caption tracks on the landing video.

### Docs and media
- The live FAQ page is generated from `docs/FAQ.md` at build time, so the two cannot differ. FAQ, README and CONCEPTS corrected where they were ahead of or behind the code.
- Screenshots, GIF, recordings and the social card were re-captured from this version.

### Tests
79 unit tests (18 new) and 22 end-to-end flows (12 new), also run against the live deployment. Each new test was checked by re-introducing its defect and confirming the test fails: 18 distinct defects, three tests strengthened before their defect was caught.

### Unchanged
Core model, JSON format version (0.1), demos, CSP. Files exported by earlier alphas import unchanged unless they contain one of the malformed ids or references described above.

### Assets
`-site.zip` (static build, base `/evidence-os-inspector/`, includes `BUILD_INFO.txt`), `-source.zip`, `demo-en.mp4`, `demo-zh.mp4`, `SHA256SUMS.txt` (with commit and build provenance).
