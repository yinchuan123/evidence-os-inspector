## Evidence OS Inspector v0.1.0-alpha.2

Point release from the pre-launch review: five independent review lenses over the deployed alpha.1 (links and assets, claims versus code, security and privacy of the live site, docs versus code, first-time visitor experience), each finding then adversarially verified by two refuters. Eleven findings stood; all are fixed or corrected here.

### Fixed
- Landing GIF and video were stretched (1280×800 box for a 960×600 file) and the video caused horizontal scrolling on every viewport; both now keep their aspect ratio inside the column.
- "Review your text" from the landing silently discarded an unsaved own workspace. It now restores the session workspace; demo workspaces are no longer written to session storage, so opening a demo cannot overwrite your work.
- Import hardening: history events are validated by id pattern and a per-type field whitelist (a malformed event id could set `nextId` to NaN and make the workspace unexportable); the placeholder label `unreviewed` is refused for stored reviews. Six new unit tests.
- The "include full source text" report option is now reachable from the UI (checkbox next to Export).
- The demo video follows the language toggle; the version selector no longer overflows the Sources pane; every text field has an accessible name; the landing link is visible on narrow screens; the review heading no longer reads "version v1".

### Corrected wording
- Privacy: the page never contacts another origin (`connect-src 'none'` blocks fetch/XHR/WebSockets; scripts, styles and media are same-origin only); the only post-load requests are demo media from the same host. Earlier text said "no network requests after load", which overstated it.
- Demo 1 has three confirmed dependencies (C4→C1, C5→C2, C5→C3), not two.
- Node 22.12 or newer is required by the pinned test runner.
- CONCEPTS/FORMAT aligned with the code: when a binding counts as superseded, history event fields, optional fields, stored review labels.

### Unchanged
Core model, JSON format version (0.1), demos, and the CSP directives. Bundles from alpha.1 remain importable.

### Verification
Typecheck, lint, 61 unit tests, production build, 10 Playwright flows (desktop + narrow) on the built site; the same flows re-run against the live GitHub Pages deployment after publishing.

### Assets
Same layout as alpha.1: `-site.zip` (static build, base `/evidence-os-inspector/`), `-source.zip`, `demo-en.mp4`, `demo-zh.mp4`, `SHA256SUMS.txt` (with commit and build provenance).
